# Таёжный Перезапуск — Оздоровительный курс за 14 дней

Веб-приложение и интерактивная платформа оздоровительного курса «Таёжный Перезапуск» (мягкое восстановление ЖКТ, печени и желчеоттока на сибирских дикоросах Горного Алтая).

## Стек технологий

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Backend / Server:** Express.js, Node.js (Fullstack архитектура)
- **Сборка:** Vite, esbuild
- **AI Integrations:** Google GenAI SDK (`@google/genai`)

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Скопируйте пример файла конфигурации:

```bash
cp .env.example .env
```

Заполните переменные:
- `GEMINI_API_KEY` — ключ API Google Gemini (при необходимости генерации сценариев/контента в AI-лаборатории).
- `APP_URL` — базовый URL приложения.

### 3. Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### 4. Проверка типов и линтинг

```bash
npm run lint
```

### 5. Сборка для продакшена

```bash
npm run build
```

### 6. Запуск продакшен-сервера

```bash
npm start
```
